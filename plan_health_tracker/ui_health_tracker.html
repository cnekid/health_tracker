• [건강 샘플 기록] 체중: 입력.weight kg
• [건강 샘플 기록] 체지방률: 입력.bodyFat %
• [건강 샘플 기록] 혈압: 입력.sys / 입력.dia
3 자동 호출 URL 스킴

측정 저장 시 shortcuts://run-shortcut?name=LogHealth... 가 자동 호출됩니다.
